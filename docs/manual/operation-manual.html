1はじめに（アプリの起動・共通操作）

このアプリは、圃場ごとの作付・収穫量・毎日の管理項目・作業実績を、その場のスマホから記録するためのものです。インターネット上のデータベース（Supabase）に保存されるので、全員が同じ内容を見ています。

1-1. 起動のしかた

  1. スマホのブラウザ（iPhone は Safari、Android は Chrome）でアプリの URL を開きます。
  2. 毎回 URL を入力しなくて済むように、ホーム画面に追加しておくと便利です。
    • iPhone：共有ボタン → 「ホーム画面に追加」
    • Android：メニュー（︙）→ 「アプリをインストール」または「ホーム画面に追加」
  3. 追加したアイコンから開くと、ブラウザの枠が出ない全画面表示になります。
ログインは現段階では不要です

今は誰でもすべての操作ができます。実際の運用に載せる段階で、作業者ごとのログイン（ID＋暗証番号）と権限の制限を入れる予定です。そのため、記録が誰の分かは 入力画面の「作業者」欄で選んだ人 で決まります。ログインした人＝記録した人、にはまだなりません。

端末操作

パソコン・タブレット（横向き）画面左のメニューから移動します。

5つのタブの役割

管理作物ごとに、その日確認することをチェックしていく。

2ダッシュボード（作業予定）

アプリを開いて最初に出る画面です。上半分が今週の作業予定カレンダー、下半分が最近の作業記録と圃場の一覧です。

2-1. 週の移動

  • ← → … 前の週・次の週へ移動します。
  • 今週 … 今週に戻します。
  • 今日の日付のカードは青枠になり、今日 の印が付きます。

2-2. 予定を追加する

  1. 予定を入れたい日のカードにある ＋ 予定を追加 を押します。
  2. 内容（必須）を入力します。例：「イチゴ 定植」「ハウス片付け」。過去に使った内容が候補として出るので、そこから選べます。
  3. 必要に応じて 日付・作物・圃場・メモ を指定します（内容以外は省略できます）。
  4. 保存 を押すと、その日のカードに予定が並びます。

2-3. 予定を完了にする・直す

  • 予定の左の丸をタップすると 完了（緑のチェック＋文字に取り消し線）になります。もう一度押すと未完了に戻ります。
  • 予定の文字の部分をタップすると編集画面が開き、内容・日付・作物・圃場・メモ・状態を直せます。
  • いらなくなった予定は、編集画面の 削除 → 削除する で消せます。

2-4. 下半分の2つのカード

カード内容
最近の作業記録直近5件の作業実績。すべて見る で実績タブの「確認」へ移動します。
圃場登録済みの圃場を4件まで表示（作物・面積つき）。すべて見る で収穫タブへ移動します。
「予定」と「実績」の違い

ダッシュボードの予定は これからやること の覚え書きです。誰が何時間やったかという 実際の記録 は、実績タブで別に登録します。予定を完了にしても実績は自動では作られません。

3実績タブ（登録・確認・集計）

実績タブは上部の3つのボタンで切り替えます。登録＝入力する、確認＝一覧で見て直す、集計＝期間ごとの合計を見る、です。

3-1. 「登録」— 作業実績を入力する

上から順に埋めていきます。必須は 日時（作業日） と 作業者 の2つだけで、他は空欄のままでも登録できます。

  1. 日時：作業日は今日の日付が最初から入っています。開始・終了の時刻を入れると、集計で作業時間が計算されます。
  2. 作業種類：ボタンから選ぶか、下の欄に直接入力します。よく使う言葉が件数つきで候補に出ます。
  3. 作物：ボタンをタップして選びます。もう一度タップで解除できます。
  4. 圃場：作物と同じくボタンで選びます。未設定のままでも登録できます。
  5. 作業者（必須）：チームごとに分かれたボタンから、その作業をした人を 全員 タップします。何人でも選べます。
  6. メモ：必要なら自由に書きます。
  7. 画面下に固定されている 内容を確認（○件） を押します。
  8. 確認の内容を見て、問題なければ 確定して登録。直したいときは 戻る でフォームに戻ります。
作業者を選んだ人数ぶん、記録が作られます

例えば同じ作業に5人を選んで登録すると、5件の記録（1人1件）がまとめて作られます。集計で「誰が何時間やったか」を出すためです。「○件」の数字が、これから作られる記録の件数です。

入力し直したとき

確認を開いたあとに内容を変えると、確認は自動的に閉じます。古い内容のまま登録されることはありません。登録が終わるとフォームは空に戻り、続けて次の作業を入力できます。

3-2. 「確認」— 登録した実績を見る・直す

  1. 上の 日ごと／週ごと／月ごと と ← → で、見たい期間を選びます（最初は今日）。
  2. 日付ごとにまとまった一覧が出ます。行には作業者・作業種類・作物・圃場・時間が並びます。
  3. 直したい行をタップすると編集画面が開きます。日時・作業者・作業種類・作物・圃場・メモを変更して 保存。
  4. 消したいときは 削除 → 削除する。

3-3. 「集計」— 期間ごとの合計を見る

区分見られる内容
期間合計のべ作業時間・レコード数・時間未設定の件数。
作業者ごと1人あたりの作業時間と件数。行をタップすると、その人の作業種類の内訳が開きます。
作業ごと作業種類ごとの合計時間と件数。棒の長さで多い少ないが分かります。
時間が集計されない場合

開始・終了の時刻が入っていない記録、終了が開始より前になっている記録は、作業時間に加えられず「時間未設定」として件数だけ数えます。時間を出したい作業は、開始・終了を必ず入れてください。

4収穫タブ（圃場ごと・収穫履歴）

上部の 圃場ごと／収穫履歴 で切り替えます。最初は「月ごと」の表示です。

4-1. 「圃場ごと」— 現況を見て、その場で記録する

圃場のカードの中に、その圃場の作付（何が植わっているか）が並びます。1つの作付カードに次の内容が出ます。

表示意味
状態のバッジこれから／生育中／収穫中／終了。
2,000株 ・ 30a ・ 定植日作付の規模。設定タブで登録した内容です。
大きい数字この作付の 累計 収穫量。
バー見込み量を登録していれば、それに対する達成度（緑）。見込みが無ければ、画面内で同じ単位のいちばん多い作付を基準にした割合（青）。
「8月 ○kg」いま選んでいる期間だけの収穫量。
最終 8/14最後に収穫した日。まだなら「未収穫」。

収穫量を記録する

  1. 記録したい作付カードの ＋ 収穫を記録 を押します。
  2. 収穫量（必須）を入力します。単位は作物ごとの設定が最初から入りますが、この記録だけ変えることもできます。
  3. 収穫日（必須。最初は今日）、収穫した人、メモ（等級・出荷先など）を必要に応じて入れます。
  4. 保存 を押すと、累計とバーがすぐ更新されます。

圃場を探す

画面上の検索欄に圃場名や作物名を入れると、一致する圃場だけが表示されます。

4-2. 「収穫履歴」— 日付順に見る・直す

  • 期間を選ぶと、その期間の収穫記録が日付順に並びます。
  • 行をタップすると編集画面が開き、量・単位・日付・収穫した人・メモを直せます。削除 もここからです。
「作付の登録が無い収穫です」と出たとき

設定タブで作付を登録していない作物の収穫は、圃場カードの下に点線の枠で別に表示されます。設定タブでその圃場に作付を登録すると、通常の作付カードにまとまります。

5管理タブ（毎日のチェック）

作物ごとに「その日確認すること」を一覧で出し、順に潰していく画面です。項目そのものは設定タブで登録します。

5-1. 日付を選ぶ

  • 最初は今日の分が開きます。← → で前日・翌日へ移動できます。
  • 今日以外を見ているときは 今日に戻す が出ます。

5-2. チェックを付ける

  1. 作物ごとのカードに、確認することが並びます。右上のバッジは 済んだ数／全部の数 です。
  2. 左の丸をタップすると確認済みになり、バッジの数字が増えます。もう一度押すと戻せます。
  3. すべて済むとバッジが緑になります。

5-3. 気づいたことを書き残す

  1. 項目名の部分をタップすると、その項目が開いてメモ欄が出ます。
  2. 気づいたことを入力し、メモ欄の外をタップすると自動的に保存されます（保存ボタンはありません）。
  3. メモが入っている項目は、閉じた状態でも「メモ: …」と1行で表示されます。
チェックは日付ごとに別々です

今日チェックを付けても、翌日は未確認の状態から始まります。前の日の状態を見たいときは ← で戻ってください。

「管理項目がまだ登録されていません」と出たら

設定タブの「管理項目」から、作物ごとに毎日確認することを登録してください（次のページ）。

6設定タブ（圃場・管理項目・単位など）

他のタブで使う「元になる情報」を登録する画面です。ここを整えておくほど、日々の入力が速くなります。

6-1. 圃場情報

圃場を登録・編集する

  1. いちばん下の ＋ 圃場を登録 を押します。
  2. 圃場名（必須。例：第1ハウス／東の畑）、面積（アール）、主な作物（メモ）、並び順、メモ を入力して 保存。
  3. 既存の圃場は、行をタップして開き 圃場を編集 から直せます。削除もこの画面からです。

並び順の数字が小さいほど、各画面のリストで上（先頭）に出ます。

作付を登録する（収穫タブに出る中身）

  1. 圃場の行をタップして開き、＋ 作付を追加 を押します。
  2. 作物（必須）を選び、状態（これから／生育中／収穫中／終了）を指定します。
  3. 株数・作付面積・定植日・収穫の見込み量・メモ（品種やハウス番号など）を必要に応じて入力し 保存。

見込み量を入れておくと、収穫タブのバーが「見込みに対して何％」の表示になります。

6-2. 管理項目

  1. 作物ごとの枠にある ＋ 項目を追加 を押します。
  2. 毎日確認すること（必須。例：潅水量の確認）を入力します。
  3. 確認のしかた・基準 を入れておくと、管理タブで項目名の下に小さく表示されます。
  4. 並び順 を指定して 保存。ここで登録した内容が、翌日以降の管理タブに毎日出ます。

6-3. 収穫量の単位

作物ごとに kg・パック・ケースなどを設定します。ここで決めた単位が、収穫を記録するときの初期値になります。

単位を変えても、すでに記録した収穫量は記録した時点の単位のままです。過去の数字が勝手に読み替わることはありません。

6-4. 表示・同期

項目内容
外観ライトモード／ダークモードを切り替えます。ハウス内や夜間はダークが見やすい場合があります。
接続状態電源マークが緑＝オンライン、グレー＝オフライン。
データベース接続マークをタップすると、データベースにつながるかをその場で確認できます。
圃場・作付・管理項目・単位は、いずれ管理者だけの操作になります

ログインを入れたあとは、この設定タブの登録・編集ができるのは管理者（米田さん）だけになります。他の人は内容の確認だけできる状態になります。

7現段階でできないこと・注意点

開発中のため、まだ入っていない機能があります。運用を始める前に把握しておいてください。

7-1. まだ入っていない機能

項目現状
ログイン未実装。誰でもすべての操作ができます。記録の「誰の分か」は入力時に選んだ作業者で決まります。
農薬・肥料の使用履歴未実装。作業種類として文字で残すことはできますが、成分・使用基準の管理はまだありません。
PDF・Excel出力未実装。報告書の書き出しは今後の対応です。
写真の添付未実装。
オフラインでの入力未実装。設定画面に「オフライン中の変更は端末に保存される」と書かれていますが、これは今後の仕様です。現段階では電波の無い場所では保存できません。
圏外での入力にご注意ください

ハウス内など電波が弱い場所で保存すると、赤い帯（保存失敗）が出ることがあります。その場合は内容が保存されていません。電波の届く場所に移動してから、もう一度入力してください。

7-2. 使うときの注意

  • 削除は元に戻せません。削除の確認が出たら、内容をよく確かめてから押してください。
  • 全員が同じデータを見ています。自分の端末だけの記録ではありません。他の人の記録も直せてしまうので、修正は自分の分か、頼まれた分だけにしてください。
  • 作業時間を集計したい作業は、開始・終了の時刻を必ず入れてください。
  • 作業種類の自由入力は表記のゆれ（「防除」「ぼうじょ」など）が出やすいので、なるべく候補のボタンから選んでください。

7-3. 権限について（ログインを入れたあとの予定）

権限できること
全権限すべて。圃場・作付・管理項目・単位を登録・編集できるのはこの権限だけ。
登録・編集実績・予定・収穫の登録と編集。設定タブの内容は見るだけ。
閲覧のみ自分に関係する記録を見るだけ。実績の登録・集計は表示されません。

8困ったときは

症状確認すること
保存すると赤い帯が出る電波状況を確認してください。設定タブの「データベース接続」をタップすると、つながるかをその場で確かめられます。
登録したはずの記録が見当たらない実績タブの「確認」で、見ている期間が合っているか確認してください（最初は今日の分だけが出ます）。← や 月ごと で範囲を広げると見つかります。
圃場や作物のボタンが出てこない設定タブでその圃場・作物が登録されているか確認してください。登録するとすぐに各画面へ反映されます。
管理タブが空設定タブの「管理項目」に、その作物の項目が登録されていません。
収穫が作付カードにまとまらない設定タブで、その圃場にその作物の作付を登録してください。
画面が古い内容のままいったん別のタブに移動して戻るか、画面を下に引いて再読み込みしてください。
改善の要望について

「この欄が押しにくい」「この並び順を変えたい」といった気づきは、そのまま伝えてください。日々の入力の速さに直結する部分から順に直していきます。
